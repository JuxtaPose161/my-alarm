# My Alarm English

Плагин-капча для [Sleep as Android](https://play.google.com/store/apps/details?id=com.urbandroid.sleep): чтобы выключить будильник, нужно ответить на вопросы по словам из своей колоды в AnkiDroid (или решить примеры, как в Alarmy).

## Установка

1. Открой [последний релиз](https://github.com/JuxtaPose161/my-alarm/releases/latest) и скачай `my-alarm.apk`. Прямая ссылка: `https://github.com/JuxtaPose161/my-alarm/releases/latest/download/my-alarm.apk`.
2. Установи APK. Android попросит разрешить установку из этого источника.
3. Открой **My Alarm English** → «Дать доступ» к AnkiDroid → выбери колоду и проверь поля кнопкой «Проверить колоду».
4. В Sleep as Android: **Настройки → Будильник → CAPTCHA** → выбери «Английский из Anki» и сложность.
5. Нажми «Попробовать» в плагине, чтобы проверить задания без будильника.

Обновления ставятся поверх старой версии, настройки сохраняются (все сборки подписаны одним ключом).

## Задания

| Тип | Что нужно сделать |
|---|---|
| Выбор перевода | Слово → выбрать перевод (EN→RU или RU→EN) |
| Аудио | Телефон произносит слово → выбрать перевод |
| Пропуск в предложении | В примере из карточки пропущено слово → выбрать его |
| Набрать слово | Перевод → написать английское слово (одна опечатка прощается в словах от 6 букв) |
| Математика | Пример, как в Alarmy |

Сложность в Sleep (1–5) задаёт число правильных ответов: 3, 4, 5, 7, 10. На 4–5 в вопросах 6 вариантов вместо 4, а примеры становятся сложнее.

Правила:
- ошибка добавляет ещё одно задание (максимум +5), а слово возвращается через пару вопросов уже как «набрать слово»;
- слова с ошибками первыми попадают в вопросы на следующее утро;
- в «наборе слова» две попытки, потом показывается ответ;
- если Anki недоступен или колода пуста, остаются только примеры, так что будильник всегда можно выключить.

## Настройка уровня

- **Колода:** выбирается из твоих колод Anki (подколоды включаются автоматически).
- **Уровень:** фильтр по тегу `B1`, `CEFR::B1` и т. п. Если в колоде нет тегов уровня, выбери «Любой» и задавай уровень выбором колоды.
- **Доп. фильтр:** любой поиск Anki, например `tag:verbs`, `-is:new`, `prop:ivl<30`.
- **Поля:** какое поле считать английским словом, переводом и примером. По умолчанию это 1-е поле, 2-е поле и поле с названием Example/Sentence/Пример.

Порядок слов на утро: вчерашние ошибки → карточки, которые сегодня к повторению в Anki → случайные из колоды. Плагин ничего не меняет в расписании Anki. Если включить «Помечать ошибки в Anki», к заметкам с ошибками добавится тег `alarm_miss`.

## Сборка

APK собирается GitHub Actions при каждом пуше в `main` (`.github/workflows/build.yml`) и публикуется в Releases. Локально: `./gradlew assembleDebug` (JDK 17, Android SDK 35).

Структура:
- `app/…/quiz` — логика заданий без зависимостей от Android (покрыта тестами `QuizLogicTest`);
- `app/…/anki/AnkiRepository.kt` — чтение карточек через ContentProvider AnkiDroid;
- `app/…/ui` — экран капчи и настройки (Jetpack Compose);
- `captcha-support/` — копия [sleep-captcha-support](https://github.com/urbandroid-team/sleep-captcha-support) (Apache 2.0). Оригинал опубликован только в закрытом jcenter, поэтому исходники лежат в проекте; изменён лишь импорт аннотаций на AndroidX.

`keystore/debug.keystore` — обычный отладочный ключ (пароль `android`). Он лежит в репозитории специально: так все сборки подписаны одинаково и ставятся поверх друг друга.
