# Ветка wakeupwithanki

Здесь только workflow, который собирает [DroidThug/WakeUpWithAnki](https://github.com/DroidThug/WakeUpWithAnki)
(коммит `d2d7537`) для личной проверки. Готовый APK лежит в артефакте `wakeupwithanki-apk` на странице запуска в Actions.

У WakeUpWithAnki и у My Alarm English одинаковое имя пакета (`com.urbandroid.mycaptcha`),
поэтому на телефоне может стоять только одно из них.
