# My Alarm English

Плагин-капча для [Sleep as Android](https://play.google.com/store/apps/details?id=com.urbandroid.sleep). Будильник (или напоминание по расписанию) не выключается, пока не выполнено задание по английскому: перевод слов из своей колоды AnkiDroid, диалог, пересказ, диктант и другие. Задания готовит и разбирает Claude по курсу, построенному на English File, и запоминает, что у тебя получается, а что нет.

Claude работает **от подписки**, без ключа API: это сессия Claude Code по расписанию. Телефон и сессия обмениваются файлами через твой приватный репозиторий на GitHub.

## Установка

1. Открой [последний релиз](https://github.com/JuxtaPose161/my-alarm/releases/latest) и скачай `my-alarm.apk`. Прямая ссылка: `https://github.com/JuxtaPose161/my-alarm/releases/latest/download/my-alarm.apk`.
2. Установи APK. Android попросит разрешить установку из этого источника.
3. Открой **My Alarm English**:
   - вкладка **Anki** → «Дать доступ» → выбери колоду и проверь поля кнопкой «Проверить колоду»;
   - вкладка **Claude** → репозиторий данных и токен GitHub (см. «Claude от подписки» ниже), уровень A1–C2, «Синхронизировать сейчас».
4. В Sleep as Android: **Настройки → Будильник → CAPTCHA** → выбери «Английский из Anki» и сложность.
5. Нажми «Попробовать» на вкладке «Сценарии» или «Задания», чтобы проверить задания без будильника.

Обновления ставятся поверх старой версии, настройки сохраняются (все сборки подписаны одним ключом).

**Почему пакет называется `com.urbandroid.mycaptcha`.** На Android 11+ приложение видит чужие приложения, только если они перечислены в его манифесте. В манифесте Sleep as Android нет общего правила для капч, есть только список конкретных пакетов, и `com.urbandroid.mycaptcha` — место в нём, оставленное под свою капчу. С любым другим именем Sleep плагин просто не найдёт. Минус: на телефоне может стоять только одна такая сторонняя капча.

Если плагина нет в списке капч, закрой Sleep принудительно (Настройки Android → Приложения → Sleep → Остановить) и открой снова: Sleep кэширует список.

## Сценарии: утро и задания по расписанию

Sleep не сообщает капче, какой будильник её открыл, поэтому набор заданий выбирается **по времени**. Срабатывает первый сценарий, в окно которого попало время.

| Сценарий по умолчанию | Окно | Разминка | Задания |
|---|---|---|---|
| Утренний будильник | 04:00–11:00 | 3 быстрые карточки | перевод слов, диалог, пересказ, план дня |
| Задание по расписанию | 11:00–04:00 | нет | «Скажи иначе», «Найди ошибки», обратный перевод, монолог, вчерашний день, диктант, пересказ, диалог |

- Утренний будильник ставь в Sleep как обычно. «Задания по расписанию» — это отдельные будильники Sleep на нужное время, с противным звуком и этой же капчей.
- Из отмеченных в сценарии заданий берётся то, которое давно не попадалось и для которого на телефоне есть готовое задание.
- **Запасной выход:** через заданное время (по умолчанию 15 минут утром и 30 днём) появляется кнопка «решить примеры вместо заданий», чтобы не опоздать. Его использование видно в истории.
- Окна, разминку, число заданий подряд и набор заданий можно менять, добавлять свои сценарии.

## Задания

Отвечать можно текстом или голосом через микрофон на клавиатуре (голосовой ввод Gboard и т. п.).

Задания от Claude готовятся заранее. Утром ответ проверяет **телефон** по критериям, которые Claude записал в задание: слова из Anki, грамматические конструкции (по шаблону), ключевые моменты, объём. Подробный разбор с исправлениями Claude пишет при следующем запуске сессии, он появляется на вкладке «Прогресс».

| Задание | Что нужно сделать | Когда засчитано на телефоне |
|---|---|---|
| Перевод слов | N слов из Anki, RU→EN и EN→RU по очереди | Слово засчитано, если ответ без ошибок, иначе карточка пропускается и вернётся в конце. Подходит любой перевод с карточки; ответы не с карточки Claude потом проверит как возможные синонимы. Без сети и без Claude |
| Диалог | Ситуация (подсказать дорогу, продиктовать рецепт, собеседование…), реплики собеседника появляются по очереди, на каждую нужно ответить | Не короче N минут, использованы N слов из Anki и M конструкций, реплики не короче нескольких слов |
| Пересказ | Прочитать или прослушать текст, текст скрывается, пересказать и ответить на N вопросов | Ключевые моменты текста, ответы по сути, M слов, объём |
| Скажи иначе | Фразу переписать заданными конструкциями | В каждом варианте нужная конструкция и смысл исходной фразы |
| Найди ошибки | Текст с ошибками под твои слабые места, выписать «неправильно → правильно» | Исправлено ≥ N−1 |
| Обратный перевод | Абзац на русском → на английский | Смысл предложений, слова и конструкции урока |
| Монолог по карточке | IELTS Speaking Part 2: минута подготовки, монолог | Все пункты, 3 слова-связки, объём |
| План дня / Вчерашний день | Рассказ о сегодняшних планах или о вчерашнем дне | Будущие или прошедшие времена, объём |
| Диктант с пропусками | Телефон читает текст, вписать пропущенные слова | Ошибок не больше допустимого, 3 проверки |
| Быстрые карточки | Выбор перевода, аудио, пропуск в предложении, набор слова, примеры | Сложность в Sleep (1–5) задаёт число карточек: 3, 4, 5, 7, 10 |

Все N и M настраиваются на вкладке «Задания».

**Будильник выключается всегда.** Если готового задания нет (не было синхронизации), вместо него даётся перевод слов, а без Anki — примеры. Если критерии задания не получается выполнить после трёх проверок, ответ уходит Claude на разбор, а вместо задания даётся перевод слов.

Живых заданий, где Claude отвечает сразу (свободный диалог, переговоры, «Объясни слово»), нет: подписку Claude можно использовать только в приложениях Anthropic и Claude Code, а не из своего приложения.

## Курс и память

- **Учебник.** Курс построен на English File (4-е издание, Oxford): те же уровни от Elementary до Advanced Plus и примерно тот же порядок грамматики и тем, плюс блок C2 в духе Cambridge C2 Proficiency. В приложении хранится только план (грамматика и темы по уровням, `course/Curriculum.kt`). Все тексты пишет Claude, из учебника ничего не скопировано.
- **Профиль ученика** — «память» репетитора, `profile.json` в репозитории данных. Его ведёт Claude после каждого разбора: статистика по каждой грамматической теме (сколько раз верно и с ошибками), трудные слова, история, сильные и слабые стороны, заметки и план «что дальше».
- **Что тренировать дальше:** первые неосвоенные темы своего уровня и самая слабая тема с прошлых уровней. Тема считается освоенной после 3 верных употреблений, если ошибок не больше половины от верных. Сюжеты заданий идут по темам уровня по кругу.
- Вкладка **«Прогресс»** показывает заметки Claude, разборы ответов, грамматику уровня (✓ освоено, ! много ошибок), трудные слова и историю.

## Claude от подписки

Anthropic разрешает подписку Claude только в Claude Code и своих приложениях, поэтому приложение само к Claude не обращается. Вместо этого:

1. **Приватный репозиторий данных**, например `my-alarm-data` (пустой, приватный). В нём:
   - `phone/state.json` — от телефона: уровень, размеры заданий, нужные виды заданий, слова из Anki;
   - `tasks/` — задания от Claude;
   - `answers/` — ответы с телефона;
   - `reviews/` — разборы от Claude;
   - `profile.json` — профиль ученика, который ведёт Claude.
2. **Токен GitHub для телефона**: GitHub → Settings → Developer settings → Fine-grained tokens → доступ только к репозиторию данных, права *Contents: Read and write*. Токен и имя репозитория вводятся на вкладке «Claude». Телефон синхронизируется раз в 3 часа, после каждого задания и по кнопке.
3. **Задание по расписанию в Claude Code** (от подписки) два раза в день по инструкции [`tutor/TUTOR.md`](tutor/TUTOR.md): разобрать новые ответы, обновить профиль, подготовить задания, проверить файлы валидатором [`tutor/validate.py`](tutor/validate.py) и запушить.

Ответы и заметки о тебе лежат только в приватном репозитории данных, а не в этом.

## Настройка колоды

- **Колода:** выбирается из твоих колод Anki (подколоды включаются автоматически).
- **Уровень (фильтр по тегу):** тег `B1`, `CEFR::B1` и т. п. Если в колоде нет тегов уровня, выбери «Любой». Это фильтр слов; уровень курса задаётся отдельно на вкладке Claude.
- **Доп. фильтр:** любой поиск Anki, например `tag:verbs`, `-is:new`, `prop:ivl<30`.
- **Поля:** какое поле считать английским словом, переводом и примером. По умолчанию это 1-е поле, 2-е поле и поле с названием Example/Sentence/Пример.

Порядок слов: вчерашние ошибки → карточки, которые сегодня к повторению в Anki → случайные из колоды. Плагин ничего не меняет в расписании Anki. Если включить «Помечать ошибки в Anki», к заметкам с ошибками добавится тег `alarm_miss`.

## Сборка

APK собирается GitHub Actions при каждом пуше (`.github/workflows/build.yml`) и лежит в артефактах запуска. Из `main` он ещё и публикуется в Releases. Локально: `./gradlew testDebugUnitTest assembleDebug` (JDK 17, Android SDK 35).

Структура:
- `app/…/course` — курс, формат файлов обмена, проверка ответов на телефоне (`LocalCheck`), сценарии (тесты `CourseLogicTest` на примерах из `tutor/examples`);
- `app/…/data` — синхронизация с репозиторием данных через GitHub API (тесты `GitHubRepoTest`);
- `tutor/` — инструкция для сессии Claude Code, валидатор файлов и примеры заданий;
- `app/…/quiz` — быстрые карточки и перевод слов (тесты `QuizLogicTest`);
- `app/…/anki/AnkiRepository.kt` — чтение карточек через ContentProvider AnkiDroid;
- `app/…/ui` — экран капчи, экраны заданий и настройки (Jetpack Compose);
- `captcha-support/` — копия [sleep-captcha-support](https://github.com/urbandroid-team/sleep-captcha-support) (Apache 2.0). Оригинал опубликован только в закрытом jcenter, поэтому исходники лежат в проекте; изменён лишь импорт аннотаций на AndroidX.

`keystore/debug.keystore` — обычный отладочный ключ (пароль `android`). Он лежит в репозитории специально: так все сборки подписаны одинаково и ставятся поверх друг друга.

## Пока не сделано

- Свой распознаватель речи и анализ произношения (как в Chatty): сейчас голос вводится микрофоном клавиатуры, произношение не оценивается. Задание «повтор за диктором» появится вместе с ним.
- Задания, где Claude отвечает сразу (свободный диалог, переговоры, «Объясни слово»): от подписки это невозможно.
- Задачи из Trello для «Плана дня»: пока план рассказывается своими словами.
