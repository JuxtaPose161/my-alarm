# My Alarm English

Плагин-капча для [Sleep as Android](https://play.google.com/store/apps/details?id=com.urbandroid.sleep). Будильник (или напоминание по расписанию) не выключается, пока не выполнено задание по английскому: перевод слов из своей колоды AnkiDroid, диалог, пересказ, диктант и другие. Задания готовит и проверяет Claude по курсу, построенному на English File, и запоминает, что у тебя получается, а что нет.

## Установка

1. Открой [последний релиз](https://github.com/JuxtaPose161/my-alarm/releases/latest) и скачай `my-alarm.apk`. Прямая ссылка: `https://github.com/JuxtaPose161/my-alarm/releases/latest/download/my-alarm.apk`.
2. Установи APK. Android попросит разрешить установку из этого источника.
3. Открой **My Alarm English**:
   - вкладка **Anki** → «Дать доступ» → выбери колоду и проверь поля кнопкой «Проверить колоду»;
   - вкладка **Claude** → вставь ключ API Anthropic, выбери уровень (A1–C2), нажми «Проверить связь» и «Подготовить сейчас».
4. В Sleep as Android: **Настройки → Будильник → CAPTCHA** → выбери «Английский из Anki» и сложность.
5. Нажми «Попробовать» на вкладке «Сценарии» или «Задания», чтобы проверить задания без будильника.

Обновления ставятся поверх старой версии, настройки сохраняются (все сборки подписаны одним ключом).

**Почему пакет называется `com.urbandroid.mycaptcha`.** На Android 11+ приложение видит чужие приложения, только если они перечислены в его манифесте. В манифесте Sleep as Android нет общего правила для капч, есть только список конкретных пакетов, и `com.urbandroid.mycaptcha` — место в нём, оставленное под свою капчу. С любым другим именем Sleep плагин просто не найдёт. Минус: на телефоне может стоять только одна такая сторонняя капча.

Если плагина нет в списке капч, закрой Sleep принудительно (Настройки Android → Приложения → Sleep → Остановить) и открой снова: Sleep кэширует список.

## Сценарии: утро и задания по расписанию

Sleep не сообщает капче, какой будильник её открыл, поэтому набор заданий выбирается **по времени**. Срабатывает первый сценарий, в окно которого попало время.

| Сценарий по умолчанию | Окно | Разминка | Задания |
|---|---|---|---|
| Утренний будильник | 04:00–11:00 | 3 быстрые карточки | перевод слов, диалог, пересказ, план дня, «Объясни слово» |
| Задание по расписанию | 11:00–04:00 | нет | переговоры, «Скажи иначе», «Найди ошибки», обратный перевод, монолог, вчерашний день, диктант, пересказ, диалог |

- Утренний будильник ставь в Sleep как обычно. «Задания по расписанию» — это отдельные будильники Sleep на нужное время, с противным звуком и этой же капчей.
- Из отмеченных в сценарии заданий берётся то, которое давно не попадалось.
- **Запасной выход:** через заданное время (по умолчанию 15 минут утром и 30 днём) появляется кнопка «решить примеры вместо заданий», чтобы не опоздать. Его использование видно в истории.
- Окна, разминку, число заданий подряд и набор заданий можно менять, добавлять свои сценарии.

## Задания

Отвечать можно текстом или голосом через микрофон на клавиатуре (голосовой ввод Gboard и т. п.).

| Задание | Что нужно сделать | Когда засчитано | Сеть |
|---|---|---|---|
| Перевод слов | N слов из Anki, RU→EN и EN→RU по очереди | Слово засчитано, если ответ без ошибок; иначе карточка пропускается и вернётся в конце. Подходит любой перевод с карточки; если ответа нет на карточке, Claude проверяет, синоним ли это | не нужна (синонимы — с Claude) |
| Диалог | Ситуация и первая реплика (подсказать дорогу, продиктовать рецепт, собеседование…), нужно продолжать разговор | Прошло N минут, использованы N слов из Anki и M конструкций. Ошибки поправляются прямо в чате | нужна |
| Переговоры с целью | Упрямый собеседник: вернуть товар без чека, перенести дедлайн… | Цель достигнута | нужна |
| Пересказ | Прочитать или прослушать текст, текст скрывается, пересказать и ответить на N вопросов | Суть передана, ответы верны, использованы M слов, достаточный объём | нужна |
| Объясни слово | Объяснить слово из Anki по-английски, не называя его | Claude угадал с 1–2 попыток, нужно N угаданных слов | нужна |
| Скажи иначе | Фразу переписать заданными конструкциями | Каждый вариант грамматически верен и сохраняет смысл | нужна |
| Найди ошибки | Текст с ошибками под твои слабые места | Найдено ≥ N−1, без ложных исправлений | нужна |
| Обратный перевод | Абзац на русском → на английский | Смысл передан, слова и конструкции урока, без грубых ошибок | нужна |
| Монолог по карточке | IELTS Speaking Part 2: минута подготовки, монолог | Все пункты, связность, объём | нужна |
| План дня / Вчерашний день | Рассказ о сегодняшних планах или о вчерашнем дне | Будущие или прошедшие времена к месту, объём | нужна |
| Диктант с пропусками | Телефон читает текст, вписать пропущенные слова | Ошибок не больше допустимого, 3 проверки | только для заготовки |
| Быстрые карточки | Выбор перевода, аудио, пропуск в предложении, набор слова, примеры | Сложность в Sleep (1–5) задаёт число карточек: 3, 4, 5, 7, 10 | не нужна |

Все N и M настраиваются на вкладке «Задания».

**Будильник выключается всегда.** Если Claude недоступен (нет сети или ключа) или задание не засчитано, вместо него даётся перевод слов, а без Anki — примеры.

## Курс и память

- **Учебник.** Курс построен на English File (4-е издание, Oxford): те же уровни от Elementary до Advanced Plus и примерно тот же порядок грамматики и тем, плюс блок C2 в духе Cambridge C2 Proficiency. В приложении хранится только план (грамматика и темы по уровням, `course/Curriculum.kt`). Все тексты пишет Claude, из учебника ничего не скопировано.
- **Профиль ученика** — это «память» репетитора. Он хранится на телефоне и уходит с каждым запросом к Claude: уровень, статистика по каждой грамматической теме (сколько раз верно и с ошибками), трудные слова, последние задания, сильные и слабые стороны и короткие заметки, которые Claude переписывает после каждого проверенного задания.
- **Что тренировать дальше:** первые неосвоенные темы своего уровня и самая слабая тема с прошлых уровней. Тема считается освоенной после 3 верных употреблений, если ошибок не больше половины от верных. Сюжеты заданий идут по темам уровня по кругу.
- Вкладка **«Прогресс»** показывает заметки Claude, грамматику уровня (✓ освоено, ! много ошибок), трудные слова и историю заданий.

## Claude

- Нужен свой ключ API Anthropic (console.anthropic.com → API Keys). Ключ хранится только в приватных файлах приложения на телефоне, запросы идут напрямую в API Anthropic. Задания и проверки оплачиваются с этого ключа.
- Модель по умолчанию — `claude-opus-5-5`. На вкладке Claude можно указать другую, например подешевле.
- Задания готовятся заранее раз в несколько часов, когда есть интернет: по 2 заготовки каждого вида. Утром нужна только проверка ответа. Если заготовки нет, задание создаётся на месте (до ~75 с), а без сети заменяется переводом слов.
- Включены резервные модели на стороне сервера: если Claude отказывается отвечать на запрос, ответ даёт другая модель. Если API не примет этот параметр, приложение повторит запрос без него.

## Настройка колоды

- **Колода:** выбирается из твоих колод Anki (подколоды включаются автоматически).
- **Уровень (фильтр по тегу):** тег `B1`, `CEFR::B1` и т. п. Если в колоде нет тегов уровня, выбери «Любой». Это фильтр слов; уровень курса задаётся отдельно на вкладке Claude.
- **Доп. фильтр:** любой поиск Anki, например `tag:verbs`, `-is:new`, `prop:ivl<30`.
- **Поля:** какое поле считать английским словом, переводом и примером. По умолчанию это 1-е поле, 2-е поле и поле с названием Example/Sentence/Пример.

Порядок слов: вчерашние ошибки → карточки, которые сегодня к повторению в Anki → случайные из колоды. Плагин ничего не меняет в расписании Anki. Если включить «Помечать ошибки в Anki», к заметкам с ошибками добавится тег `alarm_miss`.

## Сборка

APK собирается GitHub Actions при каждом пуше (`.github/workflows/build.yml`) и лежит в артефактах запуска. Из `main` он ещё и публикуется в Releases. Локально: `./gradlew testDebugUnitTest assembleDebug` (JDK 17, Android SDK 35).

Структура:
- `app/…/course` — курс, профиль ученика, сценарии, промпты и схемы ответов Claude, заготовки заданий (логика без Android покрыта тестами `CourseLogicTest`);
- `app/…/llm/ClaudeClient.kt` — запросы к Claude через официальный Java SDK Anthropic, ответы в виде JSON по схеме;
- `app/…/quiz` — быстрые карточки и перевод слов (тесты `QuizLogicTest`);
- `app/…/anki/AnkiRepository.kt` — чтение карточек через ContentProvider AnkiDroid;
- `app/…/ui` — экран капчи, экраны заданий и настройки (Jetpack Compose);
- `captcha-support/` — копия [sleep-captcha-support](https://github.com/urbandroid-team/sleep-captcha-support) (Apache 2.0). Оригинал опубликован только в закрытом jcenter, поэтому исходники лежат в проекте; изменён лишь импорт аннотаций на AndroidX.

`keystore/debug.keystore` — обычный отладочный ключ (пароль `android`). Он лежит в репозитории специально: так все сборки подписаны одинаково и ставятся поверх друг друга.
